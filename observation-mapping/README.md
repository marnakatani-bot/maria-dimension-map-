# 観測マッピング・ノート（デモ版 v0.1.2）

## このアプリの目的

思いついた観測を、その場ですぐ書き留めて、あとから探せるようにするための、個人用の記録アプリです。

書いた文章は「原文」としてそのまま残ります。アプリが勝手に文章を直したり、要約したりすることはありません。

記録は「ひとつのフォルダにしまう」のではなく、ひとつの記録にいくつでもラベルを付けられます。
同じ記録を「ひらめき」からも「7D」からも「仕事」からも、何度でも呼び出せます。

インターネットにつながっていなくても使えます。書いた内容が外に送られることは一切ありません。

---

## 起動方法

### いちばん簡単な方法（パソコン）

1. ZIPファイルを右クリックして「すべて展開」を選びます。
2. 出てきたフォルダを開きます。
3. その中の **index.html** をダブルクリックします。
4. ブラウザー（EdgeやChrome）でアプリが開きます。

これだけです。インストールも、会員登録も、パスワードもいりません。

> **大事な注意**
> 展開したフォルダは、消さずにそのまま置いておいてください。
> フォルダを消すとアプリが開けなくなります（記録そのものはブラウザー側に残りますが、開く入口がなくなります）。
> デスクトップやドキュメントフォルダなど、分かりやすい場所に置くのがおすすめです。

この開き方は「ふつうのローカル利用」です。ネットにつながっていなくても、記録・検索・書き出しなど、すべての機能がそのまま使えます。

### ショートカットを作ると便利です

index.html を右クリック →「その他のオプションを表示」→「送る」→「デスクトップ（ショートカットを作成）」
これでデスクトップから一発で開けます。

### アプリのように「インストール」したい場合（PWA）について

このデモ版には、アプリとしてインストールするための設定ファイル（manifest.webmanifest と service-worker.js）を同梱しています。
ただし、**index.html をダブルクリックして開いた場合（アドレスが `file://` で始まる場合）、この仕組みは働きません。**
ブラウザーの決まりで、`file://` では service worker が登録できないためです。

* インストールやホーム画面追加を使うには、**HTTPSに対応したWebサーバー**（レンタルサーバー、社内サーバー、GitHub Pages などの公開ページ置き場）にフォルダを置く必要があります。
* **クラウドドライブ（OneDrive、Googleドライブなど）にフォルダを置くだけでは、PWAとして動くとは限りません。** 多くの場合、ファイルの閲覧画面が開くだけで、アプリとしては登録されません。
* PWA機能が使えなくても、記録・検索・編集・バックアップといった**基本機能はすべて問題なく動きます**。心配はいりません。

**このデモ版では、まずWindowsパソコンで index.html を開いて使う方法をおすすめします。**

## パソコンでの使い方

1. 画面の上のほうにある大きなボタン **＋ 新しい観測を記録** を押します。
2. 大きな四角い枠に、思いついたまま文章を書きます。ここが「原文」になります。
3. タイトルは空でもかまいません。空のときは、本文の1行目から自動で短い名前が付きます。
4. 下にあるラベル（現実／観測／ひらめき／3D〜9D／シフト中 など）を押して選びます。何個でも選べます。もう一度押すと外れます。
5. 自由タグは、枠に言葉を入れて Enter キーか「追加」ボタンを押すと付きます。
6. いちばん下の **保存する** を押すと保存されます。

### 記録を探す

* 一覧画面の「キーワード検索」に言葉を入れると、その言葉を含む記録だけが並びます。
* 「ラベルで絞り込む」を押すとラベルの一覧が開きます。押したラベルで絞り込まれます。
* ラベルは組み合わせられます。たとえば「ひらめき」と「7D」を両方押すと、その両方に当てはまる記録だけが出ます。
* 元に戻したいときは **すべての記録に戻す** を押します。

### 記録を直す・増やす・消す

一覧のカードを押すと全文が開きます。その画面の下に3つのボタンがあります。

* **編集する**：内容を書き直します。
* **複製する**：同じ内容のコピーを作ります。書き換えて別の記録にしたいときに使います。
* **削除する**：消します。押すと「本当に消しますか」と確認が出ます。「いいえ」を押せば消えません。

## Androidスマートフォンでの使い方

> **はじめにお読みください**
> Androidで、パソコンと同じように「ファイルから直接HTMLを開く」方法は、**端末の機種やブラウザーの種類・バージョンによって動作が変わります。**
> 開けないことも、開けても保存がうまくいかないこともあり、このデモ版では**正常に動くことを保証できません。**
> そのため、**まずはWindowsパソコンでお使いいただくことをおすすめします。**
> スマートフォンでどうしても使いたい場合は、下の方法をお試しください。

### 方法A：ファイルから開いてみる（お試し）

1. ZIPファイルをスマートフォンに送ります（自分あてのメールに添付するのが簡単です）。
2. 「Files」や「ファイル」アプリでZIPを開き、展開します。
3. 展開したフォルダの中の **index.html** を押し、Chromeで開きます。

開けた場合は、パソコンと同じように使えます。
ただし、この開き方では記録の保存先が不安定になることがあります。**大事な記録は必ずJSONで書き出して保管してください。**

### 方法B：Webサーバーに置いて開く（安定します）

HTTPSで開けるWebサーバー（レンタルサーバーやGitHub Pagesなど）にフォルダごと置き、そのアドレスをChromeで開きます。
この方法なら保存が安定し、Chromeの右上「︙」→「ホーム画面に追加」から、アプリのように起動できるようになります（PWA）。
用意にはある程度のパソコン知識が必要なため、必要になったときにご相談ください。

### スマートフォンでの操作

パソコンと同じです。ボタンとラベルは指で押しやすい大きさにしてあります。
横にはみ出してスクロールすることはありません。

> **重要：パソコンとスマートフォンは自動でつながりません**
> このデモ版には同期機能がありません。
> パソコンで書いた記録はパソコンに、スマートフォンで書いた記録はスマートフォンに、それぞれ別に保存されます。
> 移したいときは、下の「バックアップ方法」でJSONファイルを書き出して、もう一方で読み込んでください。

## データの保存場所

記録は **お使いのブラウザーの中（IndexedDB という保存領域）** に保存されます。

* 保存の名前：`observation-mapping-note`
* 会員登録もサーバーも使いません。データはあなたの機械の外に出ません。
* IndexedDB が使えない状況（たとえば一部の環境で index.html をファイルから直接開いた場合）は、
  自動的に **localStorage** という別の保存領域に切り替わります。使い勝手は変わりません。

### データが消えてしまう場合（とても大事です）

次のことをすると、記録が消えます。

* ブラウザーの「閲覧履歴データの削除」で **Cookieとサイトデータ** を消したとき
* シークレットモード／プライベートモードで使ったとき（閉じると消えます）
* 別のブラウザーで開いたとき（EdgeとChromeでは別々の保存になります）
* スマートフォンの容量が足りず、システムが自動でデータを整理したとき
* パソコンを買い替えたとき

**そのため、こまめに下のバックアップをとってください。**
週に一度、あるいは大事な記録を書いた日にJSONを書き出しておけば安心です。

---

## バックアップ方法

1. 画面の右上（スマートフォンでは上部）の **バックアップ** ボタンを押します。
2. **JSONで書き出す** を押します。
3. 「観測マッピング-バックアップ-日付.json」というファイルがダウンロードされます。
4. そのファイルを、消えない場所（USBメモリ、クラウドドライブ、自分あてのメールなど）に保存します。

**Markdownで書き出す** を押すと、文章として読みやすい形（.md）でも保存できます。
こちらは読んだり印刷したりする控え用です。**復元に使えるのはJSONのほうです。**

---

## 復元方法

1. **バックアップ** ボタンを押します。
2. 読み込み方を選びます。
   * **追加して読み込む**：今ある記録を残したまま、ファイルの記録を足します。
   * **すべて置き換える**：今ある記録をすべて消してから、ファイルの記録に入れ替えます。（確認画面が出ます）
3. 保存しておいた `.json` ファイルを選びます。
4. 「〇件を読み込みました」と出れば完了です。

パソコンからスマートフォンへ記録を移すときも、この方法を使います。

---

## データ消失を防ぐための注意

* ブラウザーの履歴削除で「Cookieとサイトデータ」を消さない。消す前には必ずJSONを書き出す。
* シークレットモードでは使わない。
* 月に一度は、JSONバックアップを別の場所（クラウドや外付けメモリ）に保存する。
* 展開したアプリのフォルダを消さない。
* 大事な記録を書いた直後は、その日のうちにバックアップをとる。

## 実装済み機能

* 新しい記録の作成（本文・任意タイトル・記録日時の自動入力）
* タイトル未入力時の仮タイトル自動生成
* 情報の入口ラベル（現実／観測／ひらめき／夢／身体反応）複数選択
* 次元ラベル（3D〜9D）複数選択
* 状態ラベル（通常／複数視座／シフト中／未判定）複数選択
* 研究工程ラベル（一次観測／仮説化前／マリアメモ候補／マリアメモ化済み／論文候補／論文採用済み／Bluesky投稿済み）複数選択
* 自由タグの追加・削除
* 原文の保護（アプリは原文を書き換えません）
* 原文とは別に保存する補助欄（次元展開／整理メモ／研究への接続／関連記録）
* 記録一覧のカード表示（タイトル・日時・冒頭・全ラベル・タグ）
* 記録の全文表示
* キーワード検索（タイトル・原文・補助欄・タグを対象）
* ラベルと自由タグによる絞り込み、複数条件の組み合わせ
* 絞り込みの一括解除
* 編集・複製・削除（削除は確認画面つき）
* JSON書き出し／Markdown書き出し
* JSON読み込みによる復元（追加／すべて置き換えの選択つき）
* ライトモードとダークモードの切り替え（設定を記憶します）
* スマートフォンとパソコンの両対応
* オフライン利用（インターネット接続なしで全機能が動きます）
* PWA用ファイルの同梱（manifest.webmanifest と service-worker.js。ただし利用には別途HTTPSのWebサーバーが必要です）
* サンプル記録1件を最初から収録

* ログイン、ユーザー登録
* パソコンとスマートフォンの自動同期
* AIによる自動分類、AIによる本文の書き換え
* 外部AI（OpenAI／Claudeなど）との接続
* Notion連携、GitHub連携、Bluesky連携、自動投稿
* ネットワークグラフ、論文の自動生成

詳細画面にある **「Sol相談用にコピー」** を押すと、その記録をMarkdown形式に整えてクリップボードへコピーします。この画面からSolや外部サーバーへ自動送信はしません。コピー後、ChatGPTの会話へ貼り付けて相談してください。クリップボードへコピーできない環境では、Markdownファイルとして自動的に保存します。

## ファイル構成

```
observation-mapping-demo-v0.1.2/
├─ index.html              画面のかたち（これを開くと起動します）
├─ styles.css              見た目の設定（色・文字の大きさ・配置）
├─ app.js                  動きの中身（保存・検索・書き出しなど）
├─ manifest.webmanifest    ホーム画面に追加するときの設定
├─ service-worker.js       PWAとして使うときにオフライン起動を助ける仕組み（HTTPSのサーバー上でのみ働きます）
├─ icons/
│   └─ icon.svg            アプリ用アイコン
└─ README.md               この説明書
```

外部のインターネットサービスや有料サービスは一切使っていません。

> **別の機械へ移すときの注意**
> このフォルダをまるごとコピーすれば、**アプリ自体は**別のパソコンでも同じように動きます。
> ただし、**書きためた記録は一緒には移りません。**
> 記録はフォルダの中ではなく、お使いのブラウザーの中に保存されているためです。
> 記録も移したいときは、必ず次の手順を行ってください。
>
> 1. 今のパソコンでアプリを開き、**バックアップ → JSONで書き出す**
> 2. 書き出した `.json` ファイルを新しいパソコンへ移す
> 3. 新しいパソコンでアプリを開き、**バックアップ → 追加して読み込む**（または「すべて置き換える」）
>
> 同じことは、パソコン ↔ スマートフォンの間でも同じです。
