# 第三者AIテスト

CDMの議論を何も知らないAI（MUSE）に原典だけを読ませて、構造を正しく理解できるかを確かめます。

## 守ること

- MUSEに渡すのは、`structure.md` の写しとテストの問いだけです。
- `reviews/`、`decisions.md`、Notionの会議室・過去の候補ページは見せません。
- テスト用のNotionページは、会議室の外に1つだけ作ります。中身は `structure.md` の写しだけにします。
- MUSEへの指示では、ほかのページを探したり読んだりしないよう伝えます。
- テストは節目ごとに数問だけにします（修正のたびには行いません）。

## 記録の書き方

ファイル名：`YYYY-MM-DD_テスト名.md`

```
# テスト名
- 使った原典：structure.md（コミット）
- MUSEに渡した問い（そのまま）：
- MUSEの回答（そのまま）：
- 採点（誰が）：
- 原典の直すところ（あれば）：
```
