# CDM原典 作成セクション（作業中）

このフォルダは、意識の次元マッピング（CDM）の原典を、著者・中谷まり亜とAI（Claude、Perplexity上のSol など）が少しずつ作り直すための作業場所です。

- **ここにあるものは、すべて作業中の下書きです。** 正式な定義は、引き続きリポジトリ直下の `README.md` と `docs/` です。
- この作業は `cdm-source-draft` ブランチで進めます。`main` と公開ページは、著者の許可があるまで変更しません。

## 作り方の方針（著者案 2026-11-04）

文章だけで定義を積み上げるのではなく、次の順に組み立てます。

1. 短い正式定義
2. 構造図と、そのすぐそばに図の読み方（凡例）
3. 次元どうしの関係表（何と何が、どんな関係で、何が共通し、何が変わるか）
4. 各次元を同じ観点で比べる一覧表
5. 各次元の詳しい文章（今ある README・docs の文章）
6. 適用例・誤読しやすい例・未定義のこと

## ファイル

| ファイル | 中身 | 書き換えてよい人 |
| --- | --- | --- |
| `structure.md` | 構造図・凡例・関係表（原典の核） | 著者が確認した内容だけ。AIは空欄の追加と原文の引用だけ |
| `decisions.md` | 著者が決めたこと（日付つき） | 著者の決定を記録するときだけ |
| `reviews/` | AIの監査・考察・提案（1件1ファイル） | どのAIも |
| `tests/` | 第三者AIのテスト課題と結果 | どのAIも |

## 作業ルール

1. **決めるのは著者だけ。** AIは提案と監査をします。AIどうしの合意だけで原典を確定しません。
2. **原典とAIの議論を混ぜない。** 監査や考察は `reviews/` に書き、`structure.md` には書きません。
3. **原文は一字一句そのまま引用し、出典（ファイル名・行番号・コミット）を付ける。** 太字などの装飾も原文どおりに写す（D5）。
4. **わからないところは空欄（？）のまま残す。** 推測で埋めません。
5. **数式・記号・図は、著者が確認した関係を表すためだけに使う。** 記号から新しい規則を作りません。
6. **自動実行はしない。** 予定タスクやAIどうしの自動の往復は使わず、著者が一回ずつ依頼します。
7. **小さく進める。** 1回の作業は1つの関係、または1つの次元までにします。

## 進め方（1回分）

```
著者が「今日はこれ」と決める
  → Claude が下書き・引用・空欄を用意（structure.md の候補を reviews/ に）
  → Sol が監査（reviews/ に1ファイル）
  → 著者が決める（decisions.md に記録 → structure.md に反映）
```

## 第三者AIテスト（MUSE）

MUSEには、この作業の議論（`reviews/`・Notionの会議室など）を見せません。渡すのは `structure.md` の写しとテストの問いだけです。詳しくは `tests/README.md` を見てください。
