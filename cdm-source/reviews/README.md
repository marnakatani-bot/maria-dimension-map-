# AIの監査・考察

AI（Claude、Sol など）の監査・考察・提案を、1件1ファイルで置きます。ここに書いたことは原典ではありません。著者が決めたものだけが `decisions.md` と `structure.md` に移ります。

## ファイル名

`YYYY-MM-DD_書いたAI_テーマ.md`（例：`2026-11-05_sol_R1監査.md`）

## 中身（短く）

```
# テーマ
- 書いたAI：
- 見たもの：ファイル名・行番号・コミット
- 気づいたこと：
- 提案：
- 著者に決めてほしいこと：
```

- 原文を引くときは一字一句そのまま、出典つきで。
- 提案と、原典に書いてあることを混ぜない。
- 前のレビューに答えるときは、そのファイル名を書く。
