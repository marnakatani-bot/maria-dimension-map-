### 編集方針

1. 説明・比較は「編集要約」「編集比較」、引用枠と展開欄は原文として区別。抜粋は抜粋と明示し、全文の保存先を示す。
2. AIの初回回答、誤読、自己評価、著者の指摘、再回答を時系列で残す。第003号では、Claudeが後から自分とSOLをまとめて「熱」に気づいたと述べた表現も保存し、初回の感謝・余剰電力の案との違いを編集注で示す。
3. `Message collapsed`、相対時刻、見出しと本文の重複、原文の表記を保持。未取得部分は推測で補わず、完全エクスポートとは呼ばない。
4. 統計・外部情報・発電量・製品情報・実現可能性はAIの発言として保存し、独立検証済みの事実へ昇格させない。
5. ハッカーを歓迎する思考実験を、実際の不正侵入者へのデータ・資産・権限提供を勧める技術仕様にしない。
6. 個別思考実験とCDM公式定義を区別し、3D・4Dを優劣や発達階段にしない。著者が示していない結論・新理論を追加しない。
