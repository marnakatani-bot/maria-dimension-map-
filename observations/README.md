## ファイル構成

- index.html：第001号の公開ページ。著者提供のSubstack原文、編集要約、AIの初期解釈、著者の訂正、修正後の解釈を収録する。
- sources/001-substack-author-provided.txt：著者提供のSubstack掲載原文。受領ファイルをそのまま保存する。

## 第002号以降の追加

1. index.html に固有ID case-002、case-003…を持つ記事を追加し、ナビゲーションにもリンクを追加する。
2. 原文は sources/002-…、sources/003-… と番号を分け、受領した内容を保持する。
3. 既存の原文・初期解釈・訂正・再解釈を削除せず、追記日時と改訂理由を明示して履歴を追加する。
4. 著者の一次資料、AIの編集要約、後続の補足、探索仮説、独立テスト結果の区分を維持する。
5. 原文自体の訂正が必要な場合は、受領版を残して別の版を追加する。

CDMの公式定義や既存研究資料は、事例の解釈に合わせて変更しない。Substackの外部投稿URL・投稿日時は、提供資料で未照合とされている状態を維持する。
